# Joan Marqueno Portfolio

Source code for my personal portfolio: [joanmarqueno.vercel.app](https://joanmarqueno.vercel.app)

This site is focused on positioning my profile for Full Stack, Backend Python and Applied AI opportunities. It highlights experience in Intelligent Document Processing (IDP), document generation with LLMs, APIs, frontend development and cloud deployment.

## Stack

- Astro
- Tailwind CSS
- TypeScript
- Vercel

## What the site includes

- Clear positioning around Python, TypeScript and Applied AI
- Recruiter-focused experience and project sections
- Responsive navigation with mobile menu
- SEO improvements with canonical tags, sitemap, robots and structured data
- Project highlights including MysticMe and Kado Masajes

Add or update your CV source in `cv/cv-joan.json` and `cv/cv-joan.tex`, then rebuild:

```bash
cd cv && pdflatex cv-joan.tex && pdflatex cv-joan.tex && cp cv-joan.pdf ../public/cv-joan-marqueno.pdf
```

## Local development

```bash
npm install
npm run dev
```

## Available commands

| Command | Description |
| :-- | :-- |
| `npm run dev` | Start the local development server |
| `npm run build` | Build the production site |
| `npm run preview` | Preview the production build locally |
