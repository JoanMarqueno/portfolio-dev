## 🚀 Comandos

| Comando           | Acción                                      |
|:------------------|:--------------------------------------------|
| `npm run dev`     | Inicia servidor de desarrollo en `localhost:4321` |
| `npm run build`   | Construye el sitio para producción en `./dist/` |
| `npm run preview` | Vista previa de la build antes de desplegar |
